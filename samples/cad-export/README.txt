Набор тестовых данных «cad-export» (45 файлов) к тестовому заданию «Мини-PDM: состав изделия».

Каждый файл (*.a3d — сборка, *.m3d — деталь или стандартное изделие) — это JSON в кодировке UTF-8,
эмулирующий документ CAD-системы. Расширение не означает формат: читать нужно как JSON.

Поля:
  formatVersion  — версия формата, сейчас всегда 1
  fileName       — имя файла
  type           — Assembly | Part | StandardPart
  designation    — обозначение (у StandardPart — null)
  name           — наименование
  properties     — { material, mass }; mass — килограммы за 1 шт.
  components     — только у сборок: [{ file, count }], где file — имя файла в этой же папке

Идентификатор документа — имя файла на диске; ссылки в components указывают на него.

Внимание: набор намеренно содержит ошибочные данные. Импорт должен их обнаружить,
не прерываясь, и перечислить в отчёте.

Папка cad-export-v2 (лежит рядом в архиве) — та же модель после доработки конструктором.
Она нужна для проверки повторного импорта и версий: сначала импортируйте cad-export,
утвердите объекты, затем импортируйте cad-export-v2.
